# Mi Restaurante — Demo Web Profesional (Paquete $320)

Plantilla demo para restaurantes: menú, reservas, galería, promociones, delivery y redes sociales.

## Secciones incluidas

- Inicio (hero)
- Nosotros
- Menú / carta con precios y categorías
- Promociones
- Galería de fotos
- Horarios de atención
- Ubicación + mapa + redes sociales
- Reservas (formulario → WhatsApp)
- Enlaces a delivery (Uber Eats, Rappi, PedidosYa)

## Desarrollo

```bash
npm install
npm run dev    # http://localhost:5182
npm run build
```

El contenido del restaurante está centralizado en `src/data/restaurant.ts` para personalizar por cliente.
