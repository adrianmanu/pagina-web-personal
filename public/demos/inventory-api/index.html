StockFlow — Inventario y facturación SRI

Plataforma SaaS para control de stock, facturación electrónica con el SRI (Factuplan) y membresías con PayPhone. Esta demo funciona en el navegador sin instalar nada.

¿Qué hace este sistema?

StockFlow gestiona inventario, clientes, proveedores y emite comprobantes electrónicos (facturas, notas de crédito/débito, guías, retenciones, ATS). La demo del portafolio simula el flujo completo en tu navegador. El backend Spring Boot real se despliega en un servidor para pruebas con Factuplan y PayPhone.

Qué puedes probar en la demo

  • Entrar con un clic — cuenta demo precargada
  • Dashboard con KPIs, stock bajo y ventas recientes
  • Productos, clientes, proformas y facturación con descuento de stock
  • Facturas con estado SRI simulado (AUTORIZADO)
  • Notas de crédito/débito, guías, retenciones, liquidaciones, ATS
  • Configuración SRI y membresía (simuladas en demo)
  • Exportar inventario y facturas en PDF o Excel

Guía rápida

  1. Entra con demo — botón en el login o credenciales abajo.

  4. Documentos — explora notas, guías y retenciones.
  5. Restablecer — banner verde arriba para volver a datos iniciales.
