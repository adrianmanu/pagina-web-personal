Generador de Reportes PDF/Excel

Microservicio que genera reportes empresariales con formateo profesional.

Ejecutar localmente

cd projects/report-generator
pip install -r requirements.txt
uvicorn main:app --reload --port 5000

Docs interactivas: http://localhost:5000/docs

Ver código en GitHub

Endpoints

POST /reports/pdf
POST /reports/excel
