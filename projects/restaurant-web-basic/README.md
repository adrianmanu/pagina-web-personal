# Mi Restaurante — Demo Web Esencial (Paquete $230)

Plantilla demo del paquete esencial para restaurantes: menú con precios, horarios, ubicación, mapa y contacto por WhatsApp.

## Secciones incluidas

- Inicio (hero con foto del local)
- Menú / carta por categorías con fotos y precios
- Contacto (horarios, mapa, teléfono, WhatsApp, Instagram y Facebook)

## No incluye (disponible en Paquete Profesional)

- Nosotros / historia
- Galería de fotos
- Promociones
- Formulario de reservas
- Enlaces a apps de delivery

## Desarrollo

```bash
npm install
npm run dev    # http://localhost:5183
npm run build
```

El contenido del restaurante está centralizado en `src/data/restaurant.ts` para personalizar por cliente.
