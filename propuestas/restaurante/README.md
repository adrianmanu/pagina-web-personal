## Por qué una web y no solo Instagram

| Solo redes | Web propia |
|------------|------------|
| El algoritmo decide quién te ve | Google te encuentra cuando buscan "restaurante en [zona]" |
| El menú se pierde entre publicaciones | Carta ordenada, siempre actualizada |
| Dependes de la plataforma | El sitio es tuyo |
| Difícil compartir horarios y ubicación | Todo en un solo link para enviar por WhatsApp |
