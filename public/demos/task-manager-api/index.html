Task Manager API

API REST modular para gestión de tareas con arquitectura MVC.

Ejecutar localmente

cd projects/task-manager-api
npm install
npm run dev

API: http://localhost:4000/api/tasks

Ver código en GitHub

Endpoints

GET    /api/tasks
POST   /api/tasks
PUT    /api/tasks/:id
DELETE /api/tasks/:id
