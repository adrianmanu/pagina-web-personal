# TiendaNova — Demo E-commerce

Demo interactiva de tienda online completa para portafolio. React + TypeScript con datos en `localStorage`.

## Credenciales demo

| Rol | Correo | Contraseña |
|-----|--------|------------|
| Admin | `admin@tianova.demo` | `admin123` |
| Cliente | `cliente@demo.com` | `demo123` |

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
