API de Inventario Empresarial

Plataforma full stack para control de stock, facturación con descuento automático y dashboard con KPIs de inventario y ventas.

¿Qué hace este sistema?

StockFlow simula un entorno empresarial de inventario: gestiona productos, emite facturas que descuentan stock en tiempo real y presenta indicadores clave en un dashboard. La demo interactiva funciona en el navegador; el backend Spring Boot completo está disponible en el repositorio para despliegue local.

Qué puedes hacer en la demo

  • Iniciar sesión con cuenta demo o registrarte
  • Ver KPIs de inventario, stock bajo y ventas recientes
  • Crear, editar y eliminar productos con control de stock
  • Reponer stock rápidamente desde la lista de productos
  • Generar facturas con múltiples ítems y descuento automático de stock
  • Exportar inventario, facturas y resumen del dashboard en PDF o Excel

Guía rápida de uso

  1. Accede al sistema Usa «Entrar con demo» o las credenciales de abajo.
  2. Explora el dashboard Revisa productos activos, stock crítico y ventas del periodo.
  3. Gestiona productos Añade productos, ajusta precios y repone unidades cuando el stock sea bajo.
  4. Emite una factura Selecciona productos, confirma la venta y verifica que el stock se descuenta.
  5. Exporta reportes Desde Dashboard, Productos o Facturación, usa el menú «Exportar».
