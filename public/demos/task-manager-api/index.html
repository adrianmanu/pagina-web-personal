TaskFlow — Gestión de Tareas

Aplicación full stack con tablero kanban, prioridades, fechas límite y dashboard de productividad.

¿Qué hace este sistema?

TaskFlow organiza el trabajo en un tablero visual tipo kanban: tareas con estados, prioridades y vencimientos, más un dashboard con métricas de productividad. La demo corre en el navegador con autenticación simulada; el backend Node.js + Express completo está en el repositorio para despliegue local.

Qué puedes hacer en la demo

  • Registrarte o iniciar sesión con cuenta demo
  • Ver KPIs: tareas vencidas, % completado y próximos vencimientos
  • Gestionar tareas en tablero kanban (Por hacer, En progreso, Hecho)
  • Asignar prioridad alta, media o baja y fechas límite
  • Filtrar tareas por prioridad o estado
  • Exportar listado de tareas y resumen del dashboard en PDF o Excel

Guía rápida de uso

  1. Inicia sesión Usa «Entrar con demo» o las credenciales indicadas abajo.
  2. Revisa el dashboard Consulta estadísticas generales y tareas próximas a vencer.
  3. Abre el tablero kanban Crea una tarea nueva con título, prioridad y fecha límite.
  4. Mueve tareas entre columnas Arrastra o usa acciones para cambiar el estado (Por hacer → En progreso → Hecho).
  5. Exporta tu trabajo Desde Dashboard o Tablero, genera un reporte PDF o Excel.
