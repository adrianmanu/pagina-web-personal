Automatización de Datos Empresariales

Pipeline ETL que extrae datos de APIs REST y genera reportes analíticos.

Ejecutar localmente

cd projects/automatizacion-datos
pip install -r requirements.txt
python main.py
Ver código en GitHub

Qué hace el pipeline

  • Extrae 50 registros desde APIs REST públicas
  • Almacena en SQLite o PostgreSQL con SQLAlchemy
  • Genera resumen analítico por cliente
  • Exporta reportes CSV y JSON en /reports
GitHub Pages publica el portafolio y demos web. Las APIs y scripts Python se ejecutan en tu máquina siguiendo el README del proyecto.
