Sistema de Gestión Documental

Proyecto de titulación UTIC-ESPE — plataforma institucional para gestión y búsqueda de documentos legales.

Stack tecnológico

  • Frontend con Angular 17
  • Microservicios con Spring Boot y Java
  • Búsqueda avanzada con Elasticsearch (+70% eficiencia)
  • Autenticación OAuth2 institucional
  • Persistencia de datos no estructurados en MongoDB
  • Despliegue con Docker

Confidencialidad del código

Por políticas institucionales y un contrato de confidencialidad firmado con la UTIC-ESPE, el código fuente no puede compartirse públicamente. El repositorio se mantiene privado dentro de la organización.

Acceso al entorno de producción

El sistema en producción solo es accesible mediante VPN privada institucional. Se requiere credenciales autorizadas y conexión a la red segura de la ESPE para operar la plataforma.
